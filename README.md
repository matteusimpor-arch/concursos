# Painel de Concursos
Aplicação responsiva para cadastrar concursos, inscrições, datas de prova, prioridade e progresso.

## Supabase
1. Crie um projeto e execute `supabase/schema.sql` no SQL Editor.
2. Copie `.env.example` para `.env.local` e informe a URL e a chave anônima.
3. Execute `npm run dev`.

A política inicial serve para uso pessoal sem login. Antes de expor dados reais publicamente, adicione autenticação e políticas por usuário.
